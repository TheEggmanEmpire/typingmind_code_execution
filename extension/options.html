Code Runner Browser Bridge

This extension lets the Code Runner plugin in TypingMind read and operate your tabs. It only answers pages on the trusted hosts below that also send the pairing key.

1. Pairing key

Paste this into the Code Runner plugin setting Browser pairing key.

2. Trusted hosts

Pages allowed to use the bridge, one per line. *.example.com matches subdomains. Add your own host if you run TypingMind self-hosted or on a custom domain.
